## 调研：现有作品与来源

读取时间：2026-10-12。以下来源仅用于确认常见章节划分与讲解顺序，未复制其原文。

1. React 官方文档（中文）· 快速入门 — https://zh-hans.react.dev/learn

4. MDN · React 入门 — https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Frameworks_libraries/React_getting_started
5. 阮一峰《React 入门实例教程》 — https://www.ruanyifeng.com/blog/2015/03/react.html
6. 菜鸟教程 · React 教程（React 特点） — https://www.runoob.com/react/react-tutorial.html

调研结论：

- 常见章节划分：先立"组件与 JSX"，再讲 props / state / 事件 / 列表，最后讲组件间共享数据与界面拆解方法。本课件沿用这一顺序，并把它组织成一条从"痛点"到"结论"的论证链，而不是并列的知识清单。
- 被反复强调的核心概念：声明式视图、组件化、数据驱动渲染、单向数据流、不可变更新。
- 公认的讲解顺序：官方与中文教材普遍从最小可运行组件入手，再进入状态与交互，最后讨论状态放在哪里。
- 常见易错点（多份材料重复出现）：`class` 要写 `className`、多根元素、`onClick` 写成函数调用、直接修改数组/对象、用下标当 `key`。本课件把这些集中放在对应知识点的同页，并在第 16 页给出自检问题。
- 本课件的取舍：一课时内不展开生命周期与 `useEffect`，用"渲染 = 按 state 重算界面"一句话带过，把篇幅留给状态组织与数据流，`useEffect` 留作下一课接口。
